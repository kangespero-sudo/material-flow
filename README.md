# Stockroom · 자재관리

HTML, CSS, JavaScript와 JSON만으로 만든 자재관리 웹앱입니다. 설치할 패키지, 빌드 과정, 백엔드와 데이터베이스가 없습니다.

- 홈페이지: https://kangespero-sudo.github.io/material-flow/
- 소스: https://github.com/kangespero-sudo/material-flow

## 기능

| 화면 | 사용할 수 있는 기능 |
|---|---|
| 대시보드 | 품목 수, 현재 재고 자산, 부족재고, 대기 발주, 입출고 건수 그래프, 재고 그리드 |
| 자재 관리 | 자재 등록·수정, 수량 수정에 따른 재고조정 이력, 창고·분류·상태 필터, 검색·정렬·페이지 |
| 입출고 내역 | 입고·출고·조정 등록·수정·삭제, 날짜와 음수재고 검증 |
| 발주 관리 | 발주 등록·수정·취소, 납기 지연 표시, 전체 수량 일괄 입고와 중복 처리 차단 |
| 공급업체 | 가상 업체 연락처 등록·수정 |
| 창고 현황 | 창고 등록·수정, 창고별 자재와 평가금액 |
| 분석 리포트 | 최근 6개월 입출고 건수, 분류별 재고 자산·보충 필요 품목 |
| JSON 데이터 관리 | 전체 JSON 내보내기·가져오기·검증·교체, 가상 데이터 초기화 |
| 기능 조사 · 사용 안내 | 조사 내용, 공식 출처, 사용 방법과 구현 범위 |

## 데이터

기본 데이터는 `data/seed.json`에 있습니다. 가상 자재 18종, 공급업체 5곳, 창고 3곳과 입출고·발주 이력을 포함합니다. 샘플 데이터 기준일은 2026-10-28입니다. 실행 시 seed를 복사해 브라우저의 `localStorage`에 JSON 문자열로 저장합니다. 데이터베이스, IndexedDB, 외부 API는 사용하지 않습니다.

수정은 현재 브라우저에만 반영됩니다. GitHub 저장소의 seed 파일을 수정하거나 다른 사용자의 화면에 전송하지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료 등에 대비해 JSON을 내보내 보관하세요. 다른 기기·브라우저에서는 JSON 가져오기로 복원할 수 있습니다. 가져오기는 기존 데이터를 교체하며 형식과 수량 검사를 통과한 뒤 확인창을 표시합니다.

브라우저 저장 권한이 없으면 임시 작업임을 표시하고 JSON 백업을 안내합니다. 저장 중 공간 부족 등의 오류가 나면 기존 데이터를 유지하고 저장 실패를 표시합니다. 다른 탭에서 데이터를 바꾸면 충돌 방지를 위해 새로고침을 요구합니다.

## 계산 기준

- 현재 재고 = 기초재고 + 입고 − 출고 + 재고조정.
- 자재의 현재 수량을 수정하면 오늘 날짜의 조정 기록을 추가합니다.
- 날짜순·등록순으로 이력을 계산해 어느 시점이든 재고가 음수가 되면 저장하지 않습니다.
- 입출고 기록은 한국시간 기준 오늘까지 허용하며 미래 계획은 발주로 관리합니다.
- 재고 부족은 현재 재고가 안전재고 미만인 경우입니다. 수량 0은 품절로 따로 표시합니다.
- 자산 평가액은 현재 수량 × 현재 기준단가입니다. 회계 원가평가나 FIFO가 아닙니다.
- 서로 다른 단위의 수량은 합산하지 않고 차트는 기록 건수를 표시합니다.
- 자재는 기본 창고 한 곳에 속합니다. 동일 자재의 여러 창고 분산재고는 지원하지 않습니다.
- 발주는 전체 수량을 한 번에 입고합니다. 입고 완료된 발주는 메모만 수정할 수 있고 연결 입고 기록은 보호됩니다.

## 실행과 배포

모듈과 JSON을 불러오므로 파일 더블클릭 대신 HTTP 정적 서버나 GitHub Pages로 접속하세요. 예를 들어 Python이 있는 환경에서 이 폴더를 기준으로 `python -m http.server 4174`를 실행한 뒤 `http://localhost:4174`로 접속할 수 있습니다.

GitHub Pages는 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**로 설정합니다. main 브랜치에 변경을 올리면 자동 배포됩니다. 배포 후 JS/CSS 변경 시 `index.html`의 버전 쿼리도 갱신하면 이전 파일 캐시를 피할 수 있습니다.

## 기술 구성

- `index.html`: 앱 구조와 접근성 있는 폼·대화상자
- `style.css`: 반응형 대시보드
- `app.js`: 화면, 입력·수정·검색, 로컬 JSON 저장·파일 입출력
- `core.mjs`: 데이터 검증·재고 계산·발주 입고 처리
- `data/seed.json`: 가상 초기 데이터
- `RESEARCH.md`: 기능 조사 요약과 근거

로그인, 다중 사용자 동기화, 실제 공급업체 발송, 서버 백업, 바코드·로트 추적, 분할입고는 포함하지 않습니다. GitHub Pages에는 앱과 가상 seed만 배포하며, 웹앱에서 입력한 변경사항은 자동 게시되지 않습니다.
